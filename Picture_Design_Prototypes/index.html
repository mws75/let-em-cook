🍳 Recipe Pictures — Design Prototypes

Design-only mockups for adding photos to Let 'Em Cook. Palette, radii, and type mirror the live app (cream #fdfbf7, sage, peach, coral). Photos are Unsplash placeholders — if you're offline they fall back to a warm neutral block. Selections are now locked in (✓ below).

Chosen designs: Dashboard Tile → Option B (side thumbnail) · Explorer Card → Option A (hero top) · Recipe Card modal → Detail B header · Detail Page → Option B (side-by-side header).

Notes for review

  • Every option keeps a graceful no-photo fallback (emoji on category color) so mixed grids never look broken.
  • Image controls are owner-only; visitors just see the photo.
  • Storage will be your DigitalOcean Spaces bucket — the design doesn't assume any particular URL shape.
  • Detail page keeps print clean (photo hidden on print) to match today's behavior.
